
# 📘 Assignment: Hangman Word Guessing Game

## 🎯 Objective

Build a Hangman game in Python that uses strings, loops, and user input to let players guess a hidden word before they run out of attempts.

## 📝 Tasks

### 🛠️ Build the Hangman Game

#### Description
Create a Hangman program that randomly selects a secret word from a predefined list and lets the player guess letters until they either solve the word or use all allowed attempts.

#### Requirements
Completed program should:

- Randomly select a word from a list of possible secret words
- Accept a single letter guess from the player each turn
- Show the current word progress using blanks and revealed letters (e.g. `_ a _ _ m a n`)
- Track and display incorrect guesses remaining
- End the game with a win message when the word is fully guessed
- End the game with a lose message when the player runs out of attempts
